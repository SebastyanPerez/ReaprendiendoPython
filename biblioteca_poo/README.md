# Proyecto Biblioteca POO

Este proyecto contendrá la implementación de una biblioteca usando Programación Orientada a Objetos (POO) en Python.

Estructura sugerida:
- main.py: punto de entrada del programa
- models/: clases principales (Libro, Usuario, Biblioteca, etc.)
- utils/: utilidades y funciones auxiliares
- README.md: documentación del proyecto

Puedes modificar la estructura según tus necesidades.
