# Reaprendiendo

Este repositorio contiene todos los ejercicios, ejemplos y apuntes de mi proceso de reaprendizaje en programación con Python.

## Estructura
- **semana1, semana2, semana3, ...**: Carpetas organizadas por semanas de estudio.
- **diaX.py**: Ejercicios y ejemplos prácticos de cada día.
- **recursos/**: (opcional) Material adicional, imágenes, datasets, etc.

## ¿Cómo usar este repositorio?
Puedes navegar por las carpetas para ver los ejercicios de cada semana y día. Todos los archivos están escritos en Python.

## Notas
- Este repositorio es personal y está en constante actualización.
- Si tienes sugerencias, ¡son bienvenidas!
